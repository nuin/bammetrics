Other verbs:
  collect      Several metrics from one read of the BAM, one Picard file each.
  chain        Several steps on one BAM in one process: BAM + STEP [+ STEP ...], or --plan FILE.
  tools        List the verbs and the Picard class each runs.
  presets      List the built-in verdict presets with version and hash.
  help         Help for a verb or a Picard class.
  completions  A completion script for bash, zsh, fish, elvish or powershell.
  qc           The collectors a preset needs on one read of a BAM, then the verdict and the page.
  plan         What qc with the same options would run.
  check        Evaluate a preset over directories of metrics files, or read verdict.json files, and gate.
  report       Verdicts, sample pages and a run index from directories of Picard metrics files.
  convert      One metrics file in another format.

Picard syntax: bammetrics <PICARD CLASS> I=... O=... [KEY=VALUE ...]
